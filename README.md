# ParkSmart

Intelligent parking management and availability platform — browse lots on a live map, book a space, and (for lot owners) manage lots and see reservation activity.

- `docs/01-architecture.md` — stack, repo layout, how the pieces talk
- `docs/02-database-schema.md` — data model (Prisma schema)
- `docs/03-api-spec.md` — REST endpoints
- `docs/04-ui-spec.md` — pages and components
- `docs/plan/day-1.md` … `day-5.md` — the build plan this project is implemented against

Setup instructions (clone → run) get filled in at the end of Day 5. See `CLAUDE.md` for how an AI coding agent should use this repo.
